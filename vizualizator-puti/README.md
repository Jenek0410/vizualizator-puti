# Визуализатор алгоритмов поиска пути (A*, Дейкстра, BFS)

Курсовая работа, 3 курс.

## Статус

Версия номер 1 

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Структура

- `main.py` — точка входа
- `settings.py` — настройки
- `grid.py` — сетка
- `button.py` — кнопки
- `algorithms.py` — алгоритмы (заготовки)
- `docs/tech.rest` — техническое задание
